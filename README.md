# 🏋️ Тренировка героя — WinForms игра

Учебный проект на Windows Forms: тренируем персонажа и сражаемся с боссом.

## Функции
- **Тренировка** (+1 Силы, бесплатно)
- **Работа** (+10 Золота)
- **Магазин** (ComboBox с предметами, динамическая цена, проверка золота)
- **Таймер энергии** — каждую секунду -1 энергии
- **Арена** — бой с боссом:
  - Урон = Сила × 2
  - Шанс крита зависит от Ловкости
  - Анимация попадания (мигание)
  - Награда за победу: +100 золота
- **Передача данных между формами** через конструктор

## Как запустить
1. Создать проект Windows Forms в Visual Studio
2. Заменить файлы Form1.cs на MainForm.cs, добавить BattleForm.cs
3. Запустить (F5)
